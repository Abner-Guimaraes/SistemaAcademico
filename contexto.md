# Trabalho de Programação Orientada a Objetos

## Objetivo geral

Este projeto reúne o desenvolvimento de um trabalho acadêmico de **Programação Orientada a Objetos (POO)**. O foco é aplicar os conceitos fundamentais da orientação a objetos — classes, objetos, encapsulamento, herança, polimorfismo e abstração — na modelagem e implementação de uma solução de software.

O arquivo `contexto.md` serve como documento central do trabalho: descreve o problema, os requisitos, a arquitetura prevista e as ferramentas utilizadas ao longo do desenvolvimento.
